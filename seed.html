Database Seeder

Writes the category lists into Firestore. Non-destructive: it only sets each item's name and its wiki page title (for card imagery), using merge — existing vote counts and reasons are never touched. Safe to run more than once. No login — it relies on the temporary firestore.seeding.rules being published; re-publish firestore.rules when done.

This writes to the live prickles-or-goo database.
